## 🚀 Setup Instructions

### 📦 Install Dependencies

```bash
npm install
```

### 🔧 Run Locally

```bash
npm run dev
```

### 🏗️ Build for Production

```bash
npm run build
```

### ⬆️ Deploy to GitHub Pages

1. Make sure your `vite.config.js` contains the correct `base`:
   ```js
   base: '/RKPortfolio/',
   ```
2. Push the code to your GitHub repo `RKPortfolio`.
3. Enable GitHub Pages in **Settings → Pages** and select:
   - Branch: `main`
   - Folder: `/ (root)` or `/docs` (if you move the `dist` folder)
